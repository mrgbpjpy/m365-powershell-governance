# 04-teams-sprawl-report

## Problem
Find inactive Teams and missing owners.

## Why It Matters
Security, governance, and operational efficiency in Microsoft 365.

## What This Script Does
- Connects to Microsoft Graph
- Collects relevant data
- Exports a CSV report

## How To Run
```powershell
pwsh ./04_teams_sprawl_report.ps1
```

## Output
Creates `output-sample.csv`

## Safety
Read-only or dry-run mode.
