# M365 PowerShell Governance Toolkit

Enterprise-style PowerShell scenarios for administering, auditing, and governing Microsoft 365 and Entra ID environments.

## Scenarios
1. Bulk User Provisioning
2. MFA Audit
3. Conditional Access Audit
4. Teams Sprawl Report
5. Guest User Audit
6. Meeting Policy Export
7. Sign-in Risk Report
8. Data Access Audit
9. Inactive User Report
10. License Optimization

## Requirements
- PowerShell 7+
- Microsoft Graph PowerShell SDK
- Appropriate M365 permissions

## Safety
Scripts are report-first or dry-run by default. Test in non-production environments.
